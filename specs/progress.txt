### Tamagui Token System

- Custom colors should use semantic naming with standard scale increments (50-950)
- The `defaultConfig.tokens` from v4 includes `radius`, `zIndex`, `space`, and `size` but NOT `color`

**Learnings for future iterations:**

- The `createTokens` function must be imported from `tamagui`, not from `@tamagui/config/v4`
- The `defaultConfig.tokens` object does not include a `color` property by default - it only has `radius`, `zIndex`, `space`, and `size`
- Colors should be added to the tokens object (not themes), and themes will reference these color tokens
- Standard design system color scales use increments: 50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950 (where 500 is typically the "main" color)
- Semantic color naming (primary, success, warning, error, neutral) is preferred over generic names (blue, green, yellow, red, gray)
- Custom tokens automatically get TypeScript typing through the `TamaguiCustomConfig` module declaration
